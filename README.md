# 中英智能助手 Pro

> 版本：5.1

一个适用于 Tampermonkey 的中英翻译与英语学习助手。脚本会在网页右侧显示一个可拖动的悬浮球，提供翻译、英语句子分析、文章分析和连续英语问答功能。

## 功能

- 中英文互译
- 纯翻译：自动读取剪贴板，只输出中英翻译结果，支持单词、句子和文章
- 英语长难句快速分析和详细分析
- 英语文章快速分析和详细分析（从剪贴板读取）
- 英语问题问答
- 连续追问：自动携带最近 6 轮对话上下文
- 对话历史本地保存，刷新网页后可继续追问，也可新建对话清空上下文
- 单词/短语朗读、收藏与批量快速查询（每次最多 10 个词条）
- 结果支持折叠、重新生成和长内容分段导航
- 清空、新建对话、复制回答、读取剪贴板
- 可调整助手面板高度，悬浮球位置会自动保存
- 回答中的重点英文会加粗或下划线，并使用分级编号展示
- 液态磨砂玻璃面板，黑洞粒子背景和圆角边框动态流光
- 思考状态下黑洞粒子沿固定椭圆轨道顺时针运动
- 动画性能优化：统一动画循环、GPU 友好的位移、后台暂停和低性能设备降帧

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或其他兼容 UserScript 的浏览器扩展。
2. 打开 `temp` 文件，将全部内容复制到 Tampermonkey 的新脚本中。
3. 保存脚本并刷新网页。

建议将脚本文件重命名为 `cn-en-translator.user.js`，便于管理。脚本匹配 `http`、`https` 和 `file` 页面。

## 配置 API

1. 点击悬浮球打开助手面板。
2. 点击标题栏右侧的“⚙ 设置”。
3. 填写 API Key、Base URL 和模型名称。
4. 点击“保存设置”。

默认配置：

```text
Base URL: https://api.openclawplan.com/v1
模型: gpt-5.6-terra
```

脚本使用 Responses API，请确认所填写的服务兼容 `POST /responses` 接口。API Key 通过 Tampermonkey 的存储接口保存在本地浏览器中，不会写入网页内容。

## 使用方法

### 翻译

点击“◉ 单词与短语翻译”打开词汇查询框，在输入框中输入或粘贴中文或英文单词、短语。点击“📋 粘贴”可以读取剪贴板内容，然后选择“快速翻译”或“详细翻译”。翻译结果会按词条、释义、用法、例句等部分折叠显示，点击标题即可展开。详细翻译会补充派生串记、近义词、反义词、词根词缀、搭配和例句。翻译不依赖网页选中文字，适用于普通网页和 PDF。

### 纯翻译

点击标题栏中“？”左侧的“文”按钮。窗口会自动读取剪贴板，支持中文或英文单词、句子和文章；点击“仅翻译”后只返回译文，不附加词汇、语法或文章分析。

### 句子分析

选中英文句子后点击“⚡”，可选择快速分析或详细分析。两种分析结果都会按句子主干、结构、修饰关系、重点词组和自然翻译分节折叠，点击标题后查看对应内容。

### 文章分析

先将英文文章复制到剪贴板，再点击“📋”读取内容，然后从“📚”菜单中选择文章快析或文章详析。两种文章分析结果都支持分节折叠，单次分析最多读取 30000 个字符。

### 英语提问与追问

点击设置按钮左侧的“？”图标，输入英语问题并点击“发送问题”。回答完成后再次点击“？”即可继续追问。点击“新建对话”会清除当前问答上下文；主面板的“×”清空按钮也会清除追问历史。

支持使用 `Ctrl + Enter`（macOS 使用 `Command + Enter`）提交问题。

## 回答格式

脚本会要求模型遵循以下格式：

- 一级标题使用“一、二、三……”
- 二级条目使用“1、2、3……”
- 重点英文使用加粗或下划线
- 去除多余的 `*`、`-` 和项目符号

不同模型对格式的遵循程度可能有所差异。脚本会对常见 Markdown 符号进行额外清理。

## 界面与动画

- 面板采用半透明磨砂玻璃效果，黑洞装饰位于内容底层，减少对文字的遮挡。
- 黑洞由随机粒子组成，中心为圆形纯黑核心；粒子沿固定扁平椭圆轨道顺时针运动。
- 思考时会显示一条严格贴合面板圆角外轮廓的闭环流光，灯带从底边中点开始并先向左移动。
- 动画统一使用单一刷新循环和 `transform` 位移；页面隐藏或系统启用“减少动态效果”时会暂停动画。

## 隐私与权限

脚本需要以下 Tampermonkey 权限：

- `GM_xmlhttpRequest`：向配置的 API 服务发送请求
- `GM_getValue` / `GM_setValue`：保存 API 配置和悬浮球位置
- `@connect api.openclawplan.com`：允许访问默认 API 域名

选中的文本、剪贴板文章和提问内容会发送到你配置的 AI 服务，请在使用前确认该服务的隐私政策。

## 常见问题

### 提示“请先在设置中填写 API Key”

打开设置面板填写有效的 API Key，并确认 Base URL 正确。

### 提示网络请求失败或超时

检查网络、API 服务状态、Base URL 和模型名称。详细分析默认超时时间较长，长文本可以改用快速分析。

### 文章分析没有读取到内容

请先复制英文文章，再点击“📋”按钮。文章分析仅支持英文内容。
